# Dönem 1 Programım

İstanbul Tıp Fakültesi Dönem 1 Türkçe öğrencileri için kişisel ders programı sayfası.

**Adres:** https://ahmad2431385.github.io/donem1-program/ (GitHub Pages, bu depodan otomatik yayınlanır) Öğrenci numarasını giren öğrenci kendi amfi derslerini, uygulamalarını, PDÖ oturumunu ve seçmeli derslerini görür.

**Resmi değildir.** Veriler fakültenin yayımladığı programlardan günde altı kez (07:30, 10:30, 13:30, 16:30, 19:30, 22:30 civarı) otomatik alınır. Şüphede kalınca asıl programlara bakın.

- `index.html` – sayfa
- `data.json` – birleştirilmiş program verisi (öğrenci numaraları yalnızca tek yönlü karma olarak bulunur, isim yoktur)
- `desc.json` – ders açıklamaları
- `tools/build.py` – kaynak tablolardan `data.json` üreten betik
